# ImageGen 生成记录

本目录保留了 Chef 30 的实际生成与修复提示，作为制作记录。部分提示引用了生成期间使用的角色基准图、布局图和中间验收图，因此不能仅靠文字提示逐字重建完全相同的像素结果。

- `base-pet.md`：角色基准形象。
- `rows/`：9 个核心状态与 2 个视线行的初始提示。
- `row-retries/`：经视觉验收后采用的重绘或修复提示。
- `look-cardinals.md`：000° / 090° / 180° / 270° 四个方向锚点。
- `look-anchor-repairs/`：方向锚点的局部重绘提示。
- `jumping-calm-hover.md`：v2.1 悬停稳定姿势的实际生成与修复提示。

统一风格约束：原创 Curry 灵感的蓝金 30 号 Q 版像素角色，卷发、短胡须、护齿与篮球作为识别元素；无球队 Logo、无品牌素材、无阴影、无文字说明、无漂浮粒子或与身体分离的特效。
