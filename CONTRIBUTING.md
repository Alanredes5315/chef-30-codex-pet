# Contributing

Small fixes, animation ideas, and compatibility reports are welcome.

When changing the atlas:

1. Keep the Codex Pet v2 canvas at 1536×2288 with an 8×11 grid.
2. Preserve 192×208 cell boundaries and fully transparent unused cells.
3. Do not add official team logos, copyrighted photos, branded audio, or detached visual effects.
4. Run the v2 atlas validator and inspect every changed animation at its real display size.
5. Include before/after previews and describe which rows changed.

Please open an issue before proposing a major identity or licensing change.
